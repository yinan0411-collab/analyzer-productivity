# 耗材使用与库存管理 V2

## 新增内容
1. “打包时间”的日期直接作为耗材使用日期。
2. 拆单SO列表显示货主名称。
3. 删除上传结果中不必要的开始日期/结束日期列。
4. 新增“每周二库存记录”页面：
   - 管理员导入标准耗材主数据。
   - 员工输入实际库存托数。
   - 系统按每托数量自动换算Pieces。
   - 同一日期+耗材编码再次保存时更新原记录。
   - 支持查询与导出库存历史。

## 部署顺序
1. Supabase SQL Editor运行 `supabase_update_v2.sql`。
2. GitHub仓库替换 `app.py`。
3. GitHub仓库加入/替换 `requirements.txt`。
4. Streamlit会自动重新部署。

## 标准耗材文件字段
- 耗材编码
- 耗材名称
- 尺寸（可选）
- 每托数量
