# 员工排班与实际打卡偏差检查

这是一个 Streamlit 小程序，用于比较员工的计划班次和实际打卡时间，只输出需要复核的问题员工，并按照日期和考勤组分类。

## 功能

- 支持同时上传多个 Excel 考勤文件
- 支持统一阈值或分别设置四类阈值
  - 提前上班
  - 迟到
  - 提前下班
  - 晚下班
- 可识别：
  - 迟到超阈值
  - 早退超阈值
  - 提前上班超阈值
  - 晚下班超阈值
  - 缺上班卡、缺下班卡、整班无打卡
  - 休息日打卡
  - 有打卡无排班
- 只显示异常员工
- 按日期选择查看，并在每个日期内按考勤组分组
- 可下载 Excel，Excel 中每个日期单独一个工作表
- 合并多个文件时，可按“用户编码 + 日期 + 考勤组”自动去重

## 本地运行

1. 安装 Python 3.10 或更高版本。
2. 在项目目录打开命令行。
3. 安装依赖：

```bash
pip install -r requirements.txt
```

4. 启动：

```bash
streamlit run app.py
```

浏览器会自动打开程序。

## 上传到 GitHub

1. 在 GitHub 新建一个空仓库。
2. 把以下文件上传到仓库根目录：
   - `app.py`
   - `attendance_analyzer.py`
   - `requirements.txt`
   - `.gitignore`
3. 提交保存。

## 部署到 Streamlit Community Cloud

1. 登录 Streamlit Community Cloud。
2. 点击 **Create app**。
3. 选择刚才的 GitHub 仓库。
4. Main file path 填写：

```text
app.py
```

5. 点击部署。

## 判断说明

程序输出的是“需要复核的班次偏差记录”，不是对员工违规行为的最终认定。临时调班、批准加班、请假、培训或管理人员手工调整都可能造成计划时间与实际打卡时间不同，建议结合现场记录确认。
